# 🛒 E-Commerce Customer Segmentation

## 📌 Project Overview
This project focuses on customer segmentation using **Machine Learning**. It uses clustering techniques to group customers based on their purchasing behaviour and financial patterns.

The main objective is to identify different customer groups so businesses can better understand their customers and make data-driven marketing decisions.

## 🎯 Objectives
- Understand customer data through Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Apply K-Means Clustering to group similar customers.
- Evaluate clustering performance using the Silhouette Score.
- Visualize customer segments using PCA.

## 🛠️ Technologies & Libraries Used
- **Python** – Programming Language
- **Google Colab** – Development Environment
- **Pandas** – Data manipulation
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Scikit-learn** – Machine Learning
  - StandardScaler
  - KMeans
  - Silhouette Score
  - PCA

## ⚙️ Project Workflow

1. **Data Loading:** Importing the dataset using Pandas.
2. **Data Preprocessing:** Handling missing values and removing unnecessary columns.
3. **Exploratory Data Analysis:** Understanding data distributions using visualizations.
4. **Feature Scaling:** Applying StandardScaler to normalize numerical features.
5. **Customer Segmentation:** Using the K-Means clustering algorithm to group customers.
6. **Model Evaluation:** Evaluating clustering quality using the Silhouette Score.
7. **Visualization:** Using PCA (Principal Component Analysis) to visualize customer clusters.

## 📊 Machine Learning Algorithm

**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters based on their features.

It helps identify customer segments with similar characteristics.

## 📈 Results
The project uses clustering and visualization techniques to identify patterns in customer data and understand different customer segments.
